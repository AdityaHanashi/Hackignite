# HackIgnite 2026 🚀

**HackIgnite** is a single-page frontend website for the 24-hour inter-college coding hackathon hosted by the **Department of Computer Science & Engineering / AIML**, Jain College of Engineering and Technology (JCET), Hubballi.

---

## ⚡ Theme: Professional Aesthetic Gradient (Cyberpunk Modern)
- **Background (60%)**: Deep Midnight Obsidian & Pure Black (`#0B0F19` & `#070A12`) with smooth multi-layer radial gradient mesh
- **Secondary / Text (30%)**: Crisp White & Off-White (`#FFFFFF`, `#E2E8F0`) with gradient text accents
- **Signature Gradient**: Multi-stop Electric Cyan → Indigo → Neon Purple (`linear-gradient(135deg, #06B6D4 0%, #6366F1 50%, #A855F7 100%)`)
- **Accents**: Neon Purple (`#A855F7`, `#C084FC`) and Electric Cyan (`#06B6D4`, `#22D3EE`)

---

## 🛠️ Quick Start

This project has **zero external build dependencies**. It is a portable vanilla HTML/CSS/JS single-page application.

### Run with Node.js
```bash
node server.js
```
Then open [http://localhost:5173](http://localhost:5173) in your browser.

### Run Directly
You can simply double-click `index.html` to open it in any modern web browser or deploy directly to GitHub Pages, Vercel, or Netlify.
