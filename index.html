Guidelines

Rules and Regulations

Please read all event guidelines carefully before participating.

01
Teams have 3 to 4 members. Members may not change after registration without organiser approval.
02
All code must be written during the 24-hour build. Open-source libraries, frameworks, and APIs are allowed; pre-built full projects are not.
03
Each team submits a GitHub repository, a demo video (under 3 minutes), and a README with setup steps.
04
Plagiarism or reused projects lead to disqualification.
05
Participants must follow campus rules and safety instructions.
06
Registration fees are non-refundable.
07
The judging panel's decision is final.
08
Each team must carry a valid college ID for check-in.
